Materi lengkap tentang redirecting constructors di Dart — prinsip DRY, sintaks : this(...), dan perbandingan dengan factory constructor. Disusun secara berurutan dari slide asli.

Slide 1: Review Sesi 10 - Factory Constructors
  • Factory constructor: factory class.name()
  • Bisa return instance yang sudah ada atau subclass
  • Use cases: singleton, caching, object pools
  • Contoh cepat: factory Shape.circle() => Circle();
Slide 2: Pengantar Redirecting Constructors

✔️ Apa itu? Constructor yang "mengalihkan" ke constructor lain di kelas yang sama.
✔️ Tujuan: Mengurangi duplikasi kode (DRY principle).
✔️ Sintaks: : this(...) di initializer list.
✔️ Tidak punya body (tidak ada { }).

Contoh dasar: Point.origin() : this(0, 0); → langsung mengarah ke constructor utama.
Slide 3: Sintaks Dasar Redirecting Constructor
class Point {
  final double x;
  final double y;

  // Konstruktor utama
  Point(this.x, this.y) {
    // print('Point created');
  }

  // Redirecting constructors
  Point.origin() : this(0, 0);
  Point.onXAxis(double x) : this(x, 0);
  Point.onYAxis(double y) : this(0, y);

  @override
  String toString() => 'Point($x, $y)';
}

void main() {
  var origin = Point.origin();       // Point(0,0)
  var pointOnX = Point.onXAxis(5);   // Point(5,0)
  var pointOnY = Point.onYAxis(3);   // Point(0,3)
  print('Origin: $origin');
  print('Point on X-axis: $pointOnX');
  print('Point on Y-axis: $pointOnY');
}

Output: Origin: Point(0,0) | Point on X-axis: Point(5,0) | Point on Y-axis: Point(0,3)

Slide 5: Solusi dengan Redirecting Constructor
class Rectangle {
  final double width;
  final double height;

  // Main constructor
  Rectangle(this.width, this.height) {
    print('Rectangle ${width.toStringAsFixed(2)} x ${height.toStringAsFixed(2)} created');
  }

  // Redirecting constructors
  Rectangle.square(double side) : this(side, side);
  Rectangle.widthDefault() : this(100, 50);
  Rectangle.fromWidth(double width) : this(width, width * 0.618); // golden ratio

  @override
  String toString() => 'Rectangle(width: ${width.toStringAsFixed(2)}, height: ${height.toStringAsFixed(2)})';
}

void main() {
  var square = Rectangle.square(10);          // 10x10
  var defaultRect = Rectangle.widthDefault(); // 100x50
  var goldenRect = Rectangle.fromWidth(100);  // 100x61.80
  print('Square: $square');
  print('Default: $defaultRect');
  print('Golden Ratio: $goldenRect');
}

Keuntungan: kode bersih, final fields terinisialisasi lewat constructor utama tanpa duplikasi.

Slide 6: Redirecting Constructor dengan Named Parameters
class Person {
  final String name;
  final int age;
  final String? email;

  // Main constructor dengan named parameters
  Person({required this.name, required this.age, this.email});

  // Redirecting dengan default values
  Person.anonymous() : this(name: 'Anonymous', age: 0);
  Person.fromName(String name) : this(name: name, age: 0);
  Person.adult(String name) : this(name: name, age: 18);
  Person.child(String name, int years) : this(name: name, age: years, email: null);

  @override
  String toString() => 'Name: $name, Age: $age, Email: ${email ?? "N/A"}';
}
Contoh: Person.adult('Budi') → age=18, email null
Slide 7-8: Configuration Class & Validasi

Dalam konfigurasi, redirecting constructor memudahkan pengaturan default. Validasi bisa dilakukan di constructor utama.

class AppConfig {
  final String apiUrl;
  final int timeout;
  final bool enableCache;

  AppConfig({required this.apiUrl, this.timeout = 30, this.enableCache = true}) {
    if (timeout <= 0) throw ArgumentError('timeout > 0');
  }

  // Redirecting ke utama dengan nilai default khusus
  AppConfig.dev() : this(apiUrl: 'https://dev.api.local', timeout: 60);
  AppConfig.prod() : this(apiUrl: 'https://api.prod.com', timeout: 15);
}

Redirecting constructor tidak punya body, tapi validasi tetap bisa dijalankan di constructor yang dituju.

Slide 9: Multiple Redirecting Levels
class Product {
  final String id;
  final String name;
  final double price;
  final String category;
  final int stock;
  final DateTime? expiryDate;

  // Main constructor terlengkap
  Product({
    required this.id,
    required this.name,
    required this.price,
    required this.category,
    required this.stock,
    this.expiryDate,
  });

  // Level 1
  Product.basic(String id, String name, double price)
      : this(id: id, name: name, price: price, category: 'General', stock: 0);

  // Level 2 (dari basic)
  Product.withCategory(String id, String name, double price, String category)
      : this(id: id, name: name, price: price, category: category, stock: 0);

  // Level 3 (memanggil ke utama)
  Product.full({
    required String id,
    required String name,
    required double price,
    required String category,
    required int stock,
    DateTime? expiry,
  }) : this(id: id, name: name, price: price, category: category, stock: stock, expiryDate: expiry);
}

var basic = Product.basic('P001', 'Item 1', 10.0);
var categorized = Product.withCategory('P002', 'Item 2', 20.0, 'Electronics');
var full = Product.full(id: 'P003', name: 'Item 3', price: 30.0, category: 'Food', stock: 100, expiry: DateTime.now());

✨ Rantai redirecting mengurangi duplikasi dan konsisten dengan constructor utama.

Slide 10: Redirecting vs Factory Constructor

Redirecting Constructor

  • Tujuan: panggil constructor lain di kelas yang sama
  • Return: harus instance class ini
  • Body: tidak ada (hanya : this(...))
  • Final fields: bisa diinisialisasi
  • Use case: default parameters, convenience constructors

Factory Constructor

  • Tujuan: logic kompleks, caching, subclass
  • Return: instance yang sudah ada atau subclass
  • Body: ada (bisa berisi logic)
  • Final fields: tidak bisa (harus lewat constructor)
  • Use case: singleton, object pool, polymorphism
Kesimpulan: Redirecting untuk delegasi sederhana, Factory untuk pola kompleks.
Best Practices & Tips
Gunakan untuk:
- Default parameter values
- Convenience constructors
- Alternative ways to create objects
Hindari untuk:
- Complex logic (gunakan factory)
- Caching & Singleton
- Subclass creation
Tips:
- Keep redirecting chains short
- Document constructor purpose
- Gunakan nama yang bermakna
Slide 14: Ringkasan & Latihan

✨ Ringkasan:

  • Redirecting constructor: : this(...) tanpa body.
  • Memanggil constructor lain di class yang sama → DRY principle.
  • Mengurangi duplikasi kode, khusus untuk final fields.
  • Tidak bisa berisi logic kompleks — delegasi murni.

Latihan (Circle Class):

Buat class Circle dengan:

  • Main constructor dengan radius (final double radius)
  • Redirecting constructor fromDiameter(double diameter) → mengarah ke this(diameter/2)
  • Redirecting constructor fromCircumference(double circumference) → radius = circumference / (2*pi)
  • Redirecting constructor fromArea(double area) → radius = sqrt(area / pi)
Contoh Solusi : 
class Circle {
  final double radius;
  Circle(this.radius);
  Circle.fromDiameter(double d) : this(d / 2);
  Circle.fromCircumference(double c) : this(c / (2 * 3.14159));
  Circle.fromArea(double a) : this(sqrt(a / 3.14159));
  @override String toString() => 'Circle(r=${radius.toStringAsFixed(2)})';
}

Implementasikan di DartPad dan coba buat objek: Circle.fromDiameter(10), Circle.fromArea(78.5).
