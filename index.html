Slide 2: Redirecting Constructor + Initializer List

Apa itu? Constructor yang mengalihkan (redirect) ke constructor lain di kelas yang sama menggunakan : this(...) pada initializer list.

Initializer list dalam redirecting:
• Initializer list adalah bagian setelah : sebelum body constructor {}.
• Pada redirecting constructor, tidak boleh ada body → hanya : this(parameter) sebagai satu-satunya inisialisasi.
• Digunakan untuk menginisialisasi final fields secara tidak langsung, karena delegasi ke constructor utama akan mengisi final fields. 

//nama:Fajar rio dinata
//nim:251410025
//kelas:S12Aclass Demo {
  final int a;
  final int b;
  Demo(this.a, this.b);  // primary constructor
  
  // Redirecting: hanya initializer list : this(...)
  Demo.zero() : this(0, 0);    // ✅ benar, tidak ada body
  
  // Demo.wrong() : this(1,1) { print('error'); } // ❌ tidak boleh ada body
}

Prinsip: redirecting mendelegasikan tanggung jawab inisialisasi ke constructor target, menghilangkan duplikasi.

Slide 8: Redirecting Constructor dengan Validasi

Validasi dilakukan di constructor utama. Redirecting hanya mendelegasikan parameter, dan validasi tetap berjalan.


//nama:Fajar rio dinata
//nim:251410025
//kelas:S12Aclass BankAccount {
  final String accountNumber;
  final String ownerName;
  final double balance;

  // Konstruktor utama privat
  BankAccount._({
    required this.accountNumber,
    required this.ownerName,
    required this.balance,
  });

  // Factory publik dengan pengalihan (redirecting) dan validasi
  factory BankAccount.create({
    required String accountNumber,
    required String ownerName,
    double initialBalance = 0,
  }) {
    // Validasi
    if (accountNumber.isEmpty) {
      throw ArgumentError('Nomor akun tidak boleh kosong');
    }
    if (ownerName.isEmpty) {
      throw ArgumentError('Nama pemilik tidak boleh kosong');
    }
    if (initialBalance < 0) {
      throw ArgumentError('Saldo awal tidak boleh negatif');
    }

    // Mengalihkan ke konstruktor privat
    return BankAccount._(
      accountNumber: accountNumber,
      ownerName: ownerName,
      balance: initialBalance,
    );
  }

  // Konstruktor pengalihan (redirecting) lainnya
  factory BankAccount.fromJson(Map json) {
    try {
      return BankAccount.create(
        accountNumber: json['accountNumber']?.toString() ?? '',
        ownerName: json['ownerName']?.toString() ?? '',
        initialBalance: (json['balance'] as num?)?.toDouble() ?? 0,
      );
    } on ArgumentError catch (e) {
      throw FormatException('Data JSON tidak valid untuk BankAccount: ${e.message}');
    } catch (e) {
      throw FormatException('Kesalahan saat mem-parsing JSON untuk BankAccount: ${e}');
    }
  }

  @override
  String toString() {
    return 'Nomor Akun: $accountNumber, Pemilik: $ownerName, Saldo: \$${balance.toStringAsFixed(2)}';
  }
}

// Contoh penggunaan
void main() {
  // Membuat akun baru
  var account = BankAccount.create(
    accountNumber: '1234567890',
    ownerName: 'Fajar Rio Dinata',
    initialBalance: 500000,
  );
  print(account);
  // Output: Nomor Akun: 1234567890, Pemilik: Fajar Rio Dinata, Saldo: $500000.00

  // Membuat akun dari JSON
  var jsonData = {
    'accountNumber': '9876543210',
    'ownerName': 'Budi Santoso',
    'balance': 750000.50,
  };
  var accountFromJson = BankAccount.fromJson(jsonData);
  print(accountFromJson);
  // Output: Nomor Akun: 9876543210, Pemilik: Budi Santoso, Saldo: $750000.50

  // Contoh error validasi
  try {
    var invalidAccount = BankAccount.create(
      accountNumber: '',
      ownerName: 'Test',
      initialBalance: 100,
    );
  } catch (e) {
    print('Error: ${e}'); // Error: Nomor akun tidak boleh kosong
  }
}

Slide 10: Redirecting vs Factory Constructor

✅ Redirecting

  • Panggil constructor lain di class sama
  • Return harus instance class ini
  • Tidak ada body → : this(...)
  • Use case: default values, convenience

🏭 Factory

  • Logic kompleks, caching
  • Bisa return subclass atau existing instance
  • Ada body, bisa pakai logika
  • Use case: singleton, object pool
Slide 11: Praktik 2 - API Response Model dengan Redirecting

Membangun model respons API yang memiliki berbagai bentuk input (JSON, manual error, success) namun tetap terpusat pada constructor utama. Redirecting memudahkan pembuatan objek dari berbagai skenario.


//nama:Fajar rio dinata
//nim:251410025
//kelas:S12Aimport 'dart:core';

class ApiResponse {
  final bool success;
  final T? data;
  final String? error;
  final int statusCode;
  final DateTime timestamp;

  // Main constructor
  ApiResponse({
    required this.success,
    this.data,
    this.error,
    required this.statusCode,
    required this.timestamp,
  });

  // ✅ Success response (diperbaiki)
  ApiResponse.success(T data)
      : this(
          success: true,
          data: data,
          error: null,
          statusCode: 200,
          timestamp: DateTime.now(),
        );

  // ✅ Error response (diperbaiki)
  ApiResponse.error(String error, int statusCode)
      : this(
          success: false,
          data: null,
          error: error,
          statusCode: statusCode,
          timestamp: DateTime.now(),
        );

  // ✅ Not found (sudah benar)
  ApiResponse.notFound()
      : this(
          success: false,
          data: null,
          error: 'Resource not found',
          statusCode: 404,
          timestamp: DateTime.now(),
        );

  // ✅ Unauthorized (sudah benar)
  ApiResponse.unauthorized()
      : this(
          success: false,
          data: null,
          error: 'Unauthorized access',
          statusCode: 401,
          timestamp: DateTime.now(),
        );

  // From JSON (factory constructor)
  factory ApiResponse.fromJson(
    Map json,
    T Function(dynamic) fromJsonT,
  ) {
    return ApiResponse(
      success: json['success'] ?? false,
      data: json['data'] != null ? fromJsonT(json['data']) : null,
      error: json['error'] as String?,
      statusCode: json['statusCode'] ?? 500,
      timestamp: json['timestamp'] != null
          ? DateTime.parse(json['timestamp'])
          : DateTime.now(),
    );
  }

  @override
  String toString() {
    return 'ApiResponse(success: $success, data: $data, error: $error, statusCode: $statusCode, timestamp: $timestamp)';
  }
}

// Contoh penggunaan
void main() {
  // Success response
  var success = ApiResponse.success('Data loaded');
  print(success);
  // Output: ApiResponse(success: true, data: Data loaded, error: null, statusCode: 200, timestamp: 2025-01-04 12:34:56.789)

  // Error response
  var error = ApiResponse.error('Bad Request', 400);
  print(error);
  // Output: ApiResponse(success: false, data: null, error: Bad Request, statusCode: 400, timestamp: ...)

  // Not found
  var notFound = ApiResponse.notFound();
  print(notFound);
  // Output: ApiResponse(success: false, data: null, error: Resource not found, statusCode: 404, timestamp: ...)

  // Unauthorized
  var unauthorized = ApiResponse.unauthorized();
  print(unauthorized);
  // Output: ApiResponse(success: false, data: null, error: Unauthorized access, statusCode: 401, timestamp: ...)

  // From JSON
  Map jsonData = {
    'success': true,
    'data': 'User profile data',
    'statusCode': 200,
    'timestamp': DateTime.now().toIso8601String(),
  };
  var fromJson = ApiResponse.fromJson(jsonData, (data) => data.toString());
  print(fromJson);
}
Mengapa redirecting berguna di API response? Menghindari duplikasi assignment final fields, memastikan konsistensi (misal success=true tidak punya errorMessage). Semua logika tetap di constructor utama.

//nama:Fajar rio dinata
//nim:251410025
//kelas:S12Aimport 'dart:core';

class User {
  final String id;
  final String username;
  final String email;
  final DateTime createdAt;
  final bool isActive;

  // Constructor dengan initializer list
  User({
    required String id,
    required String username,
    required String email,
    DateTime? createdAt,
    bool isActive = true,
  })  : id = id,
        username = username,
        email = email,
        createdAt = createdAt ?? DateTime.now(),
        isActive = isActive {
    print('User $username created!');
  }

  // ✅ Redirecting constructor untuk Guest (diperbaiki)
  User.guest()
      : this(
          id: 'guest_${DateTime.now().millisecondsSinceEpoch}',
          username: 'Guest',
          email: 'guest@example.com',
          createdAt: null,
          isActive: false,
        );

  // ✅ Redirecting constructor dari username (diperbaiki)
  User.fromUsername(String username)
      : this(
          id: 'user_${username.toLowerCase()}',
          username: username,
          email: '${username.toLowerCase()}@example.com',
          createdAt: null,
          isActive: true,
        );

  // ✅ Redirecting constructor dengan validasi (diperbaiki)
  // Catatan: Validasi TIDAK BISA dilakukan di redirecting constructor
  // Solusi: Gunakan factory constructor untuk validasi
  factory User.create(String email, String password) {
    // Validasi dilakukan di sini (dalam factory)
    if (!email.contains('@')) {
      throw ArgumentError('Invalid email');
    }
    if (password.length < 8) {
      throw ArgumentError('Password too short');
    }

    // Setelah validasi, panggil constructor utama melalui redirecting
    return User(
      id: 'user_${DateTime.now().millisecondsSinceEpoch}',
      username: email.split('@').first,
      email: email,
      createdAt: null,
      isActive: true,
    );
  }

  @override
  String toString() {
    return 'User(id: $id, username: $username, email: $email, createdAt: $createdAt, isActive: $isActive)';
  }
}

// Contoh penggunaan
void main() {
  // Membuat user biasa
  var regularUser = User(
    id: '001',
    username: 'johndoe',
    email: 'john@example.com',
    createdAt: DateTime.now(),
    isActive: true,
  );
  print(regularUser);

  // Membuat guest user
  var guest = User.guest();
  print(guest);

  // Membuat user dari username
  var userFromName = User.fromUsername('AliceWonder');
  print(userFromName);

  // Membuat user dengan validasi (menggunakan factory)
  try {
    var validUser = User.create('budi@example.com', 'password123');
    print(validUser);
  } catch (e) {
    print('Error: $e');
  }

  // Contoh validasi gagal
  try {
    var invalidUser = User.create('invalid-email', 'short');
  } catch (e) {
    print('Error: $e');
  }
}}

Slide 14: Keuntungan Redirecting dengan final fields

Tanpa redirecting, final fields tidak bisa diinisialisasi setelah constructor body. Redirecting memungkinkan berbagai bentuk constructor sambil mempertahankan final.

class ImmutableUser {
  final String id, name;
  ImmutableUser(this.id, this.name);
  ImmutableUser.guest() : this('guest_0', 'Guest User');
  ImmutableUser.withId(String id) : this(id, 'Anonymous');
}
Slide 14: Ringkasan & Latihan Akhir

📌 Ringkasan Materi

  • Redirecting constructor: NamaConstructor(...) : this(parameter)
  • Tidak memiliki body → hanya initializer list
  • Mengurangi duplikasi kode (DRY) dan ideal untuk final fields
  • Bisa multiple level redirecting, asal akhirnya ke main constructor
  • Praktik API Response menunjukkan bagaimana redirecting menyederhanakan factory-like tanpa kehilangan imutabilitas.

Latihan: Class Circle dengan Redirecting (diameter, keliling, luas)

class Circle {
  final double radius;
  Circle(this.radius);
  Circle.fromDiameter(double d) : this(d / 2);
  Circle.fromCircumference(double c) : this(c / (2 * 3.14159265359));
  Circle.fromArea(double a) : this(sqrt(a / 3.14159265359));
  String toString() => 'Circle(radius=${radius.toStringAsFixed(2)})';
}

void main() {
  print(Circle.fromDiameter(10));     // radius=5
  print(Circle.fromCircumference(31.4159));
  print(Circle.fromArea(78.5398));
}
